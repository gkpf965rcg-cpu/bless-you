Bless You

Privacy

Nothing leaves your Mac.

Bless You is a sneeze detector. It does not have accounts, analytics, advertising, crash reporting, or telemetry. There is no server that receives your audio or usage.

Microphone

The app asks for the microphone only so it can hear a sneeze and say “bless you.” Audio is processed in memory on your device, classified locally, and discarded. Bless You does not record, store, upload, or transmit microphone audio.

What is saved on this computer

Sensitivity, whether the app should start at login, and a count of sneezes it has blessed. These stay in local preferences. They are not audio, and they are not sent anywhere.

Network

The Mac app is sandboxed without network permission. It does not check for updates by itself. New versions are downloaded from this website over HTTPS. This download page does not use analytics or third-party scripts.

This website

Host this page on HTTPS. Fonts and scripts are served from the same site. The disk image’s SHA-256 checksum is published next to the download so you can verify the file you received.
